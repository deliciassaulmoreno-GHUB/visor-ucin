# __38b. Escalas de valoración de encefalopatía hipóxico-isquémica (EHI).__

Tener en cuenta que es una escala no validada para las primeras seis horas de vida.

## __b) Escala de graduación García-Alix__
En proceso de validación para las primeras 6 horas de vida
| **Gravedad** | {2} **Manifestaciones clínicas** |
|---|---|---|
| {3} **Leve** |
| *Capacidad para despertar* | {2} Normal. |
| *Tono muscular* | {2} Hipotonía de distribución proximal superior. |
| *Respuestas motoras* | {2} Cantidad normal o ligeramente disminuida, calidad normal. |
| *Reactividad* | {2} Hiperexcitabilidad: reflejos tendinosos exagerados, clonus, y/o temblor. |
| **Moderada** | A | B |
| *Capacidad para despertar* | Letargia o estupor moderado. | Convulsiones aisladas o repetitivas. |
| *Tono muscular* | Alteración del tono muscular. | |
@p 2
| *Respuestas motoras* | Disminuidas pero de calidad normal. | |
| *Reactividad* | Reflejos miotáticos disminuidos y reflejos primitivos débiles. | |
| **Grave** | A | B |
| *Capacidad para despertar* | Coma o estupor severo. | Signos de disfunción del troncoencéfalo. |
| *Tono muscular* | Hipotonía generalizada, flacidez o postura tónica sostenida. | |
| *Respuestas motoras* | Ausentes o estereotipadas: actitudes que remedan decorticación o descerebración o respuestas de triple flexión, convulsiones repetitivas o estado epiléptico. | |
| *Reactividad* | Reflejos primitivos ausentes. | |
! En el PDF la columna B ocupa todas las filas de su grado: «Convulsiones aisladas o repetitivas» es la alternativa B de toda la encefalopatía moderada, y «Signos de disfunción del troncoencéfalo» la de toda la grave.

Estados de conciencia utilizados en la escala de graduación García-Alix
| **Normal** | Normal. Despierta espontáneamente. |
|---|---|
| **Embotado** | Despierta con relativa facilidad pero precisa estimulación y mantiene la alerta > 6 segundos. |
| **Letargia** | Despierta con cierta dificultad a estímulos molestos. Mantiene la alerta breves segundos (<6 segundos). |
| **Estupor** | Despierta con dificultad a estímulo doloroso, vuelve rápidamente al "sueño" tras cesar estímulo. |
| **Coma** | No despierta ante estímulos nociceptivos. |
