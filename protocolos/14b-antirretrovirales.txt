# DOSIFICACION DE ANTIRRETROVIRALES EN EL RECIÉN NACIDO
| | |
|---|---|
| **Zidovudina (AZT / ZDV)** // **sol oral 10 mg/ml** | **__EG >35 semanas__** // Oral **4 mg/kg/12h** // Intravenoso **1,5 mg/kg/6h iv** ó **3 mg/kg/12h** (pasar a oral cuando sea posible) // **__EG 30 - 35 semanas__** // Oral. Primeras 2 semanas: **2 mg/kg/12h;** semanas 3-4 : **3 mg/kg/12h** // Intravenoso: 2/3 dosis oral (Primeras 2 semanas **1,3 mg/kg/12h**; semanas 3-4: **2,6 mg/kg/12h)** // **__EG <30 semanas__** // Oral **2 mg/kg/12h** // Intravenoso: 2/3 dosis oral (**1,3 mg/kg/12h**) |
| **Lamivudina (3TC)** // **sol oral 10 mg/ml** // No existe formulación iv | **2 mg/kg/12h** oral // Dosis no establecida en prematuros. |
| **Nevirapina (NVP)** // **sol oral 10 mg/ml** // No existe formulación iv | **__EG >35 semanas__** // Oral. Primera semana: **2 mg/kg/24h** oral, segunda semana: **4 mg/kg/24h** oral // ^*^ Si madre NVP durante el embarazo o al menos 3 días antes del parto: retrasar inicio de NVP __hasta las 48h de vida__ y aumentar dosis. Dosis 48h - día 14: **4 mg/Kg/24h** oral (NVP inductor enzimático, pasa barrera placentaria). // **__EG <35 semanas__** // Dosis única oral; sólo si madre no ha recibido NVP 200 mg vo 2-3 h antes del parto // Dosis **2 mg/kg** oral (dosis única) |
! En el PDF las dosis intravenosas de 1,3 y 2,6 mg/kg/12h van en rojo.
