| **EDAD APARICIÓN** | **CAUSAS** |
|---|---|
| Feto | Trombopenia aloinmune // Infección congénita (CMV, toxoplasma, rubeola, VIH, sífilis, parvovirus B19, etc) // Enfermedad autoinmune materna (LES, PTI, etc) // Aneuploidía (trisomías del 13, 18 y 21) // Enfermedad hemolítica por isoinmunización Rh severa // Trombopenias hereditarias (trombopenia amegacariocítica, Wiskott-Aldrich, Kasabach-Merritt, TAR, etc) |
| Neonato (<72 horas de vida) | Prematuridad // Insuficiencia placentaria // Asfixia // Infección perinatal (Streptococos, E coli, listeria, etc) // Coagulación Intravascular diseminada // Trombopenia aloinmune // Enfermedad autoinmune materna (LES, PTI…) // Infección congénita (CMV, toxoplasma, rubeola, VIH, sífilis, parvovirus B19…) // Trombosis venosa y arterial (aorta, vena renal…) // Enfermedades hematológicas (leucemia congénita, síndrome hemofagocítico…) // Trombopenias hereditarias (trombopenia amegacariocítica, Wiskott-Aldrich, Kasabach-Merritt, TAR, etc) // Enfermedad metabólica (alteraciones del metilmalónico) // Medicamentosa |
| Neonato (>72 horas de vida) | Sepsis // Enterocolitis necrotizante (NEC) // Infección congénita (CMV, toxoplasma, rubeola, VIH, sífilis, parvovirus B19, etc) // Enfermedad autoinmune materna (LES, PTI, etc) // Trombopenias hereditarias (trombopenia amegacariocítica, Wiskott-Aldrich, Kasabach-Merritt, TAR, etc) // Enfermedad metabólica (alteraciones del metilmalónico) // Inducida por heparina (niños ingresados en UCI) // Medicamentosa |
