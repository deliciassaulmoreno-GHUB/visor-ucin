# TEMA 39. PROTOCOLO DE ANALGESIA FARMACOLÓGICA Y NO FARMACOLÓGICA PARA PREVENCIÓN Y TRATAMIENTO DEL DOLOR POR __PROCEDIMIENTOS__ EN NEONATOLOGÍA.
Autoría: Itziar Marsinyach Ros. Fecha de actualización: abril 2025.

## __MEDIDAS COMUNES A TODOS LOS PROCEDIMIENTOS__
- Prevención: confirmar la necesidad de la técnica (promover monitorización no invasiva, agrupar procedimientos/extracciones).
- Agrupar tarea con manipulación para respetar el sueño.
- Realizar valoración previa-durante y tras el procedimiento con escala validada (PIPP-R).
- Valoración de dolor mediante escala validada para procedimientos (PIPP-R).

## __MEDIDAS PARA PREVENCIÓN-ANALGESIA POR PROCEDIMIENTO (TABLA).__
| **PROCEDIMIENTO** | **CONTROL DE DOLOR** |
|---|---|
| Punción del talón | Acondicionamiento de la zona (valorar calentamiento). // Succión con endulzante (lactancia materna, sacarosa 24%, glucosa 30%) __2 minutos antes__ del procedimiento. // Posicionamiento, arropamiento. Favorecer extracción en canguro. // Contención por ayudante (preferiblemente los padres). // Uso de lanceta mecánica aprobada para edad gestacional del paciente. |
| Extracción venosa | Succión con endulzante (lactancia materna, sacarosa 24%, glucosa 30%) __2 minutos antes__ del procedimiento. // Posicionamiento, arropamiento. Contención por ayudante (preferiblemente los padres). // Evitar movimientos bruscos y posturas dolorosas de los miembros. |
| Punción lumbar | Succión con endulzante (lactancia materna, sacarosa 24%, glucosa 30%) 2 minutos antes. // Posicionamiento, arropamiento. // Valorar analgesia farmacológica con fármaco de acción rápida (ej. Ketamina). |
| Intubación // Colocación de tubo de tórax // Canalización vías centrales | Analgesia no farmacológica antes del procedimiento: evitar estrés (arropamiento, contención, calor y succión). Contención por ayudante // Elección del fármaco analgésico – mayor experiencia con: opiáceos (Fentanilo 1-3mcg/kg/dosis por rapidez de acción) y valorar, __si precisa__, sedación en recién nacidos a término con midazolan (0,05-0,3mg/kg/dosis). // En pacientes extubados, valorar (si edad gestacional > 34 semanas) ketamina intravenosa 1-3mg/kg/dosis. // Evitar relajantes musculares en neonatos (intubación difícil). |

| Catéter umbilical | Medidas no farmacológicas. |
| Sonda nasogástrica | Medidas no farmacológicas, lubricar la sonda. |

Se puede aplicar una gota con el chupete o una gasa empapada (lactancia materna, sacarosa 24%, glucosa 30%). // Posicionamiento, arropamiento. Contención por ayudante (preferiblemente los padres). // Aspiraciones cortas. Esperar a recuperación. // La eficacia de la analgesia farmacológica (opiáceos) para tratamiento de dolor relacionado con procedimientos cortos, arroja resultados controvertidos. // Si inestabilidad respiratoria: premedicar con fentanilo iv .en bolo. |

@p 2

Uso limitado de medidas farmacológicas para procedimientos por falta de evidencia de su seguridad a largo plazo en fármacos distintos de los opiáceos y datos controvertido de su eficacia a dosis habituales para procedimientos cortos.
Fármacos de uso restringido por haberse relacionado con posibles efectos adversos sobre el neurodesarrollo: Ketamina, Propofol, Midazolan, etc.
