| **OCTREÓTIDO** // *Análogo somatostatina* // *__Ampollas 100 mcg/ml__* | **Indicación:** ausencia de mejoría tras 5-7 días de nutrición parenteral. // // **Acción:** Disminuye las secreciones y perfusión sanguínea digestiva. Favorece la vasoconstricción linfática. También inhibe la TSH, insulina, glucagón y GH. // // **NO suele ser eficaz si:** PVC elevada o trombosis del territorio de la vena cava superior. | - Perfusión continua → Iniciar a 1 mcg/kg/hora. // - Incrementar cada 24 horas 1 mcg/kg/hora. // - __Dosis máxima:__ 10 mcg/kg/hora. // - __Duración tto:__ mínimo 5-7 días. // - Para retirar: disminuir de manera gradual en 2-7 días. // // **Preparación:** Diluir con SSF (preferiblemente). // - Se puede administrar vía central o vvp. // - __2 concentraciones estándar:__ // **Dosis __<__ 5 mcg/kg/hora:** 500 mcg hasta 50 ml (10 mcg/ml) // **Dosis > 5 mcg/kg/hora:** 1200 mcg hasta 50 ml (24 mcg/ml) | Esteatorrea, vómitos, distensión abdominal, colelitiasis, hiperglucemia, hipoglucemia, bradicardia sinusal, rubor, edema, estreñimiento, disfunción tiroidea, hipertransaminasemia, prolongación QT. Posible relación con NEC e hipertensión pulmonar. // // **Pruebas previas a realizar:** EEG (descartar QT largo), ecografía abdominal (descartar colelitiasis) y función tiroidea. |
| **SILDENAFILO** | Inhibidor de la 5-fosfodiesterasa, se usa para el tratamiento de la hipertensión pulmonar. // // **Indicación:** También se puede usar en quilotórax asociados a malformaciones linfáticas. | **Dosis oral:** iniciar a 0,5 mg/kg cada 8 horas, aumentar hasta 1 mg/kg cada 8 horas. | Hipotensión, incrementa el riesgo de retinopatía en prematuros. |
| **PROPRANOLOL** | Betabloqueante no cardioselectivo. // // **Indicación:** También se puede usar en quilotórax asociados a malformaciones linfáticas. | **Dosis oral:** 1 mg/kg/día cada 8 horas. // Se podría aumentar la dosis. | Bradicardia, hipotensión, broncoespasmo, hipoglucemia. // **Contraindicaciones:** bradicardia, shock cardiogénico, bloqueo, insuficiencia cardiaca no controlada. |
| **DEXAMETASONA** | Disminuye el tono vascular e inhibe la carga de volumen en el conducto torácico. | **Dosis iv:** 0,5 mg/kg/día durante 5 días. Valorar subir hasta 1 mg/kg/día. | HTA, linfopenia, eosinofilia, hiperglucemia, infecciones. |
