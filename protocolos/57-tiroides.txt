# PROTOCOLO 20b. FUNCIÓN TIROIDEA ANORMAL EN CUALQUIERA DE LOS CONTROLES

[**__Hipertiroidismo bioquímico sin síntomas.__** // Inicialmente no tratamiento, control en 1-2 semanas // Considerar metamizol vía oral 0,2-0,5 mg/ kg/ día / 12h // **__Hipertiroidismo bioquímico con síntomas.__** // Iniciar **metamizol** 0,2-0,5 mg/ kg/ día / 12 horas via oral . // **-Si hiperactividad simpática**: Ingreso hospitalario. Añadir betabloqueantes 2 mg/ kg/ día cada 12 horas. // **-Si inestabilidad hemodinámica o Distrés Respiratorio:** Ingreso en UCI. Añadir lugol, 1 gota ( 0,05 ml ) tres veces al día o Yoduro potásico 1 gota ( 0,05 ml ) 1 vez al día.]
v
[Controles TSH / T 4 libre cada 1-2 semanas. Disminuir dosis metamizol cuando T4 libre se normalice, hasta suspensión ( media 1-2 meses )]
---
[**__Hipotiroidismo central o primario:__** // Repetir TSH / T4 libre en 1 semana -> // Iniciar levotiroxina 10 mcg / kg /día si T4 libre persite baja en nuevo control // Controles cada 2-3 semanas para ajuste de dosis de levotiroxina // En caso de patrón de hipotiroidismo central ( T4 libre baja y TSH inapropiadamente normal, anticuerpos Anti TSI negativos) estudiar eje hipofisario]
