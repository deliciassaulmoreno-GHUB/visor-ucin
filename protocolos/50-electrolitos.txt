## 2. BICARBONATO SÓDICO
| {5} ***3. BICARBONATO SÓDICO*** |
|---|---|---|---|---|
| {5} Tratamiento acidosis metabólica y reposición. |
| {5} **DOSIFICACIÓN** |
| {5} __PCR o hiperpotasemia severa__: 1 mEq/kg diluido al medio iv. // __Acidosis metabólica__: // HCO3 requerido (mEq)=déficit de HCO3 (mEq) x 0,3 x peso corporal (kg). // Administrar la mitad y luego valorar la necesidad del resto. |
| {5} **PREPARACIÓN** |
| **PRESENTACIÓN** | **CONCENTRACIÓN** | **DILUCIÓN Y ADMINISTRACIÓN** | **TIEMPO** | **VÍA** |
| **Bicarbonato sódico 1/6M** (0,16 mEq/ml). Viales de 250 y 500ml. // **Bicarbonato sódico 1M** (1 mEq/ml). Ampolla de 10 ml. | Recomendada: 0,16mEq ml. (Vial 1/6M). // Máx: 0,5mEq/ml. | Administrar directamente (1/6M) o diluir con SSF o API (Bicarbonato 1M). Según prescripción. | Bolo rápido no excediendo los 10mEq/min. // Perfusión continua | VC // VVP |
| {5} **ESTABILIDAD** |
| {5} Desechar restante tras administración. Dilución estable 24 horas a TªA. Almacenamiento de viales o ampollas a TªA. |
| {5} **MONITORIZACIÓN** |
| {5} EAB (vigilar alcalosis metabólica y cifras de calcio y potasio) |
| {5} **PRECAUCIONES** |
| {5} Vigilar necrosis tisular. Mirar cuadro compatibilidades. |

## 3. CLORURO DE SODIO
| {5} ***CLORURO DE SODIO*** |
|---|---|---|---|---|
| {5} Solución para casos de hiponatremia. Hipocloremia. Hiperhidratación hipotónica. |
| {5} **DOSIFICACIÓN** |
| {5} La dosis depende del déficit de sodio a partir de condiciones clínicas, electrolitos y valores de equilibrio ácido-base: // - Basales 2-3 mEq/kg. // - Fórmula de déficit de sodio: (Na deseado – Na obtenido) x 0.6 x Kg. // - Si Na < 120mEq/L Obnubilación y convulsiones Cl Na 3% 1-3ml/Kg. // - Hipovolemia: SSF al 0,9% a 10ml/kg |
| {5} **PREPARACIÓN** |
| **PRESENTACIÓN** | **CONCENTRACIÓN** | **DILUCIÓN Y ADMINISTRACIÓN** | **TIEMPO** | **VÍA** |
| **CLNA 20%** amp 10ml. ( 32,4mEq= 1,98mg de Na). // **SSF 0,9%** viales de 10, 50,250, 500, y 1000ml. | Máx: 3% = (0,479mEq/ml) | -Para CLNA 3%: Diluir 10ml de NaCl 20% + 90ml de SSF 0,9%. // -Para goteo base consultar prescripción médica. // -SSF 0,9% administrar directamente. | No administrar a más de 1mEq/kg/h. | VVP // VC |
| {5} **ESTABILIDAD** |
| {5} Almacenamiento ampolla a TªA. Dilución estable 24 horas a TªA. Desechar ampolla tras su uso. |
| {5} **MONITORIZACIÓN** |
| {5} TA, EAB. |
| {5} **PRECAUCIONES** |
| {5} Flebitis. |
