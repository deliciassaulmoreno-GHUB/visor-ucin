# 23. PROTOCOLO DE ANEMIA NEONATAL
*Ana Rodríguez Sánchez de la Blanca. Septiembre 2024.*

Los tipos más frecuentes de anemia en el neonato son la anemia fisiológica y la anemia de la prematuridad. No obstante, existen diversas etiologías responsables de un descenso de hemoglobina en el período neonatal que pueden clasificarse en tres grupos, atendiendo al mecanismo fisiopatológico principal:

## DIAGNÓSTICO DIFERENCIAL
| **PÉRDIDAS SANGUÍNEAS** | **HEMÓLISIS** | **DÉFICIT DE PRODUCCIÓN** |
|---|---|---|
| **PATOLOGÍA EMBARAZO** // • Transfusión feto-fetal // • Transfusión feto-materna // • Corioangiomas | **INMUNE** // • Incompatibilidad ABO y Rh // • Enf. autoimune materna | **HIPOPLÁSICA FISIOLÓGICA** // • Término // • Pretérmino |
| **CAUSAS OBSTÉTRICAS** // • Desprendimiento de placenta // • Placenta previa // • Vasa previa // • Inserción velamentosa cordón | **NO INMUNE** // • Alteraciones del hematíe // - Defectos membrana // - Enzimopatías // - Hemoglobinopatías // • Infecciones // • Déficit de vitamina E // • Anemia hemolítica microangiopática // • Coagulación intravascular diseminada | **APLÁSICA CONGÉNITA** // • Blackfand- Diamond // • Fanconi // • Idiopática // // **APLÁSICA SECUNDARIA** // • Infecciones // • Leucemia congénita // • Postransfusión intrauterina |
| **SANGRADO NEONATAL** // • Hemorragia intracraneal // • Hemorragia retroperitoneal // • Rotura hepática / esplénica // • Hemorragia gastrointestinal // • Enf. Hemorrágica del RN | | |

## APROXIMACIÓN DIAGNÓSTICA INICIAL
Entre las pruebas complementarias de primera línea a solicitar se encuentran un hemograma y frotis sanguíneo con recuento de reticulocitos, una bioquímica básica con bilirrubina fraccionada, el grupo sanguíneo y Rh y un test de Coombs directo:
| **RETICULOCITOS** | **BILIRRUBINA** | **TEST DE COOMBS** | **MORFOLOGÍA** | **DIAGNÓSTICO** |
|---|---|---|---|---|
| Normal/ ↓ | Normal | Negativo | Normal | Anemia fisiológica // Anemia hipoplásica congénita // Anemia aplasia |
| Normal / ↑ | Normal | Negativo | Normal | Hemorragia aguda |
| Normal / ↑ | Normal | Negativo | Microcíticos hipocrómicos | Hemorragia crónica (feto-fetal/ feto-materna) |
| ↑ | ↑ | Positivo | Normal | Hemólisis inmune (aloinmune/ autoinmune) |
| Normal / ↑ | ↑ | Negativo | Alterada | Esferocitosis; enzimopatías; hemoglobinopatías |

## INDICACIONES PARA TRANSFUSIÓN DE CONCENTRADO DE HEMATÍES
- La recomendación principal es que la sangre empleada para transfusión en el neonato corresponda a una bolsa de corto almacenamiento, esto es 2-3 días.
- Se recomienda dividir la bolsa de un mismo donante en diferentes alícuotas.
- El volumen habitual de infusión es 15 ml/kg que podrá fraccionarse en 2 ocasiones separadas por 12-24 horas.
- El tiempo de infusión es de 2-3 horas.
