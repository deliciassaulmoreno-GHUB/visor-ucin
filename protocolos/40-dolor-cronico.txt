# TEMA 40. PROTOCOLO DE ANALGESIA FARMACOLÓGICA Y NO FARMACOLÓGICA PARA PREVENCIÓN Y TRATAMIENTO DEL DOLOR SUBAGUDO/CRÓNICO
Autoría: Itziar Marsinyach Ros.
Fecha de actualización: marzo 2025.

**__TIPOS DE DOLOR SUBAGUDO O CRÓNICO NEONATAL__** – ventilación mecánica, dolor postoperatorio, dehiscencia de heridas, fracturas patológicas, etc.

## __MEDIDAS COMUNES A TODOS LOS PACIENTES:__
- Agrupar tarea con manipulación para respetar el sueño.
- Valoración de dolor prolongado con escala validada: COMFORT-NEO.
- Manipulación cuidadosa, cambio postural con contención, succión con endulzantes (lactancia materna o sacarosa 24%, ver protocolo) y evitando movimientos bruscos.
- Favorecer presencia de los padres y fomentar su participación en la identificación de dolor.

## __FARMACOTERAPIA__
| **FÁRMACO** | **CARACTERÍSTICAS** |
|---|---|
| **PARACETAMOL** | **Grupo**: AINEs. // **Indicación**: dolor agudo, subagudo o crónico. Primera línea para tratamiento de dolor. No útil para dolor por procedimientos (1) // **Forma de administración:** dosis intermitentes. Inicio acción en 30 minutos. // **Dosis**: 7,5mg/kg/dosis cada 6-8 horas intravenoso u oral/enteral. // **Datos seguridad:** múltiples estudios. Precaución en pretérminos y evitar en pacientes con daño hepático. Osmolaridad muy elevada. Prolonga el tiempo de protrombina. // **Presentación**: solución enteral 100mg/ml, infusión intravenosa 1000mg/100ml. // **Efectos secundarios:** afectación hepática. |
| **METAMIZOL MAGNÉSICO o SÓDICO.** | **Grupo:** Pirazolona. Efecto analgésico, espasmolítico y antipirético. // **Indicación:** dolor subagudo o crónico **__refractario__** a tratamiento con paracetamol y opioides. // **Forma de administración:** dosis intermitentes o perfusión continua. // **Seguridad:** Uso fuera de ficha técnica en neonatos y lactantes pequeños. Uso restringido en EEUU y algunos países europeos. Pocos datos de seguridad. No utilizar en prematuros. // **Dosis:** pauta intravenosa 20-40mg/kg/dosis cada 6-8 horas. Pauta oral/enteral 10-15 mg/kg/dosis cada 6-8 horas. Infusión continua 3,3 a 6,6 mg/kg/hora. // **Presentación:** i.v. Nolotil® (metamizol magnésico) ampollas 2g/5ml y solución oral Metalgial® (metamizol sódico) 500mg/ml. // **Efectos secundarios:** hipotensión, leucopenia, neutropenia y trombopenia. |
| **CLORURO MÓRFICO** | **Grupo:** Opioides. // **Indicación:** Segunda línea para tratamiento de dolor agudo/subagudo/crónico y primera línea en dolor intenso/agitación. // **Forma de administración:** intravenosa o subcutánea en dosis intermitentes o perfusión continua. // **Seguridad:** estudios a corto y largo plazo de seguridad en pacientes a término y pretérmino. // **Dosis:** bolos a 0,05-0,1mg/kg/dosis cada 4-6 horas y perfusión continua 5 a 20mcg/kg/hora. // **Presentación:** ampollas 1mg/1ml. // **Efectos secundarios**: depresión respiratoria, íleo intestinal, retención urinaria, hipotensión, tolerancia, abstinencia, náuseas y vómitos. |
| **FENTANILO** | **Grupo:** opioide sintético. // **Indicación:** Segunda línea para tratamiento de dolor agudo/subagudo/crónico y primera línea en dolor intenso/agitación. // **Forma de administración:** intravenosa en perfusión continua (efecto rápido de corta duración en bolos, ideal para procedimientos: ver protocolo PROCEDIMIENTOS). // **Seguridad:** estudios a corto y largo plazo de seguridad en pacientes a término y pretérmino. // **Dosis:** Infusión continua 1-10mcg/kg/hora. // **Presentación:** ampollas 150mcg/3ml. // **Efectos secundarios:** rigidez torácica, depresión respiratoria, íleo intestinal, retención urinaria, hipotensión, tolerancia y abstinencia. |
| **MIDAZOLAN** | **Grupo:** Benzodiacepinas. // **Indicación:** Tratamiento de dolor (como coadyuvante) y/o estrés de tercera línea en pacientes ya tratados con opiáceos. // **Forma de administración:** perfusión continua (efecto rápido y poco duradero muy útil en bolos para procedimientos: ver protocolo PROCEDIMIENTOS). // **Seguridad:** no recomendado su uso en población neonatal (especialmente pretérminos) por estudios a largo plazo con peores resultados en neurodesarrollo y relacionado con neuroapoptosis en modelos animales neonatales. Ponderar riesgo/beneficio en paciente grave. // **Dosis:** Infusión continua 1 a 4mcg/kg/minuto. // **Presentación:** ampollas 1mg/1ml o ampollas 15mg/3ml. // **Efectos secundarios:** depresión respiratoria, hipotensión, tolerancia. |
| **DEXMEDETOMIDINA** | **Grupo:** Agonistas alfa-2. // **Indicación:** Tratamiento de dolor/estrés de cuarta línea en pacientes ya tratados con opiáceos/midazolan que han desarrollado taquifilaxia o para rotación de pauta de sedo-analgesia. Uso de primera línea en pacientes cardiópatas (individualizar) con trastornos del ritmo cardíaco. // **Forma de administración:** Infusión continua. // **Seguridad:** escasos estudios de seguridad a medio-largo plazo en neonatos. Fármaco muy extendido en población pediátrica y adultos // **Dosis:** perfusión continua 0,1 a 0,5 mcg/kg/hora. Inicio a bajas dosis en neonatos (respecto población pediátrica o adulta) por menor aclaramiento plasmático // **Presentación:** vial 100mcg/ml. // **Efectos secundarios:** bradicardia, hipotensión (simpaticolíticos). |
